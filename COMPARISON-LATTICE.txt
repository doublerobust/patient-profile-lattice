Adopted concepts, independently implemented
- Three orthogonal dimensions and four canonical views.
- Domain collapse yielding a single timeline per patient.
- Time collapse yielding a patient-by-domain summary.
- Patient collapse yielding a domain-by-calendar-window cohort summary.
- Click summary -> enumerate exact contributors -> inspect original provenance.
- Smooth camera destinations with direct-manipulation interruption.
The task additionally requires angle-driven projections during free rotation; this is implemented by camera-normal detection, not by switching to independent tabs.

Rejected / deliberately not adopted
- External source code, styling and data generator: no reuse license verified. The 60-patient generated synthetic dataset IS now included under Yue's explicit data-only authorization; no external generator or inference code is shipped.
- Claude/agent integration or fallback chat commands: outside scope and would change privacy/service behavior.
- Signal-inference rules (Hy's law, AE after death, missing steroid, dosing gap): outside scope and not authoritative in the local clinical engine.
- Event-aligned patient exclusion and response confirmation rules: would alter interpretation/counts; retained fixed calendar dates and pinned analysis rules.
- Arm-specific percentages: no compatible arm analysis added. Local cohort view reports distinct patients with displayed source starts / current visible patients, explicitly not incidence/prevalence or an arm comparison.
- Header-click clinical sort derivations: retained all six existing sorts and their definitions.

Summary definitions / safeguards
These are display aggregations, not new clinical endpoints. Inputs are existing visible marks at the current tier. Source IDs deduplicate sentinel copies. Canonical source marks supply starts/end states so a last-dose sentinel cannot shift a source into a different onset bin. Patient-layer cells count distinct source records. Cohort cells group original starts into fixed 30-calendar-day bins anchored at the initial view's earliest complete source/sentinel date; incomplete starts have a separate bucket. Denominator is current visible patient count, explicitly distinct from the analytical roster denominator. Domain hide, focus, tier and zoom may affect display summaries but do not mutate analytical specification/counts. Zero displayed records does not mean no disease. A patient can contribute to multiple bins/domains. No durations are imputed.

Limitations
Dense overview requires zoom/focus for exact readings. Axis transitions shrink geometry continuously but aggregate glyph replacement happens at an angular threshold rather than a complete continuous morph. Camera state is session-only under the existing adapter convention, not added to the pinned replay schema. Imported labs remain preserved but unrendered; toxicity grade is not inferred to be AESEV. No current performance claim, independent visual/clinical review, or deployment approval. See README.md and HANDOFF-LATTICE.txt for the resumed implementation, executed tests and outstanding checks.
